# 电影院在线购票系统数据库设计

这是一个基于 SQL Server 的电影院在线购票业务数据库设计项目，使用 T-SQL 实现数据库结构、示例数据和查询。

## 项目内容

数据库包含影院、影厅、电影、场次、座位、用户、订单、支付、优惠券、评论和管理员等业务数据，共设计 14 张表。

脚本还包含外键、唯一约束和检查约束，常用查询索引，场次与订单详情视图，可用座位数计算函数，以及影厅座位生成存储过程。

## 如何运行

1. 准备 SQL Server，并使用 SQL Server Management Studio 连接数据库服务器。
2. 打开 `cinema_ticket_system.sql`。
3. 在测试环境中执行脚本，创建数据库并插入示例数据。

**注意：脚本会删除并重建 `cinema_ticket_system` 中已有的项目数据表，请勿在存有重要数据的数据库中直接运行。**

## 项目范围

本仓库展示数据库层的设计与 SQL 实现，不包含前端页面、后端接口或真实支付功能。
